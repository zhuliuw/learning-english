Counts

How many times each page was opened

GitHub Pages cannot store a visit log. The counts live at Abacus (abacus.jasoncameron.dev), in the namespace zhuliuw-learning-english. A request sends the page path and the time. No name is stored, and nothing typed in a lesson is uploaded. That server can see the network connection. Anyone who knows the namespace can read these numbers, and can add to them. The numbers appear one by one.
