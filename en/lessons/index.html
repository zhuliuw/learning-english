Lesson index

Only the ninety-six lessons already here, for adults who use Chinese. The six-month path is on six months: each week, one listening, one reading, one speaking, and one writing lesson. Listening, speaking, and writing take about fifteen minutes. Reading takes about twenty. Month 1 uses lessons 1–4; month 2 uses lessons 5–8; month 3 uses lessons 9–12; month 4 uses lessons 13–16; month 5 uses lessons 17–20; month 6 uses lessons 21–24.
