Five things · printable

This week

For adults who already work. Five things on any five days. The other two days have no lesson. Listen, speak, and write once each, about fifteen minutes, and read once, about twenty. On the fifth day, rest, or look only at the one change you wrote down. Tick the boxes on paper. This site does not remember what you checked.

If you have not read How to learn, read that page first. One lesson, one job, and one change to keep.

List

  1. One listening lesson Start with From open to close if you have not done it. If you have, pick another listening lesson from the lesson index.
  2. One reading lesson Start with Find who does what if you have not done it. If you have, pick another reading lesson.
  3. One speaking lesson Start with From open to close. Record on your phone. This site does not receive it. If you have done that lesson, pick another speaking lesson.
  4. One writing lesson Start with Your own deadline. Write in the box on the lesson page. There is no score. If you have done that lesson, pick another writing lesson.
  5. Rest, or review one change Do not open a new lesson. If one thing from this week did not hold, look only at that.

Use the browser’s print to keep this page, and tick it on paper. Next week is the same five things. Pick the lessons from the lesson index.
